HubSpot deal closed-won

What happens here

Listens for a HubSpot deal transitioning to closed-won (or accepts a manual test run payload in n8n). Reads the deal ID, line items, currency, and billing contact without writing to any external system.

Inputs & touchpoints
  • HubSpot closed-won deal trigger
  • Deal amount, line items, and contact fields
  • Manual test run payload in n8n
Gate & stop condition
Imported inactive — read-only trigger. The workflow imports inactive in n8n so no live deals are processed until credentials and test runs are verified.
Imported inactive by default Idempotent per HubSpot deal ID Invoices stay draft/unsent by default Hard stop before live send
