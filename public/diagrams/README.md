# Interactive workflow diagrams

Self-contained HTML architecture diagrams for five Prewired AI packs, generated with Gemini 4 Neon for the draft `/templates/<slug>` pages.

These are architecture maps of the draft packs, not live product screenshots. No third-party assets or network requests.

Packs: manager-digest, speed-to-lead, booking-no-show, invoice-sync, support-triage-agent.
