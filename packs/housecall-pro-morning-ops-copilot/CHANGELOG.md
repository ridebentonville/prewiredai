# Changelog

## v0.1.0 (draft)

- First draft of the Housecall Pro CSV-First Morning Ops Copilot: a read-only weekday-morning digest for the owner that unifies (1) unscheduled, late, and needs-office-action jobs, (2) finished jobs with no invoice (or an unsent invoice) and past-due invoices, and (3) high-value estimates still awaiting a response after the shop's configured follow-up cutoff, ranked by dollar value for a human call.
- CSV-first by design. Housecall Pro's Open API and webhooks are officially MAX-only, so v0.1.0 has no Housecall Pro connection at all: one importable n8n workflow (`workflow.n8n.json`, 18 executable nodes, 6 sticky notes), built from `hcp_logic.cjs` by `build_workflow.cjs`. Intake by email attachment, watch folder, or webhook upload. No HTTP Request node. Imported inactive; every Schedule, webhook, and Gmail trigger disabled; testMode on; source defaults to fictional sample data; owner-only delivery; placeholder credentials only.
- Zero write-back. No customer SMS, email, review request, On-My-Way text, or reminder blast. Deliberate Deletes: automated estimate/invoice reminders, review requests, receptionist, QuickBooks sync, Zapier replacement, any Housecall Pro write-back.
- CSV mapper for Jobs, Invoices, and Estimates exports: case/punctuation/space/underscore/hyphen-insensitive header aliases, required-column validation with a plain-language Heads-up that lists the headers seen, report detection by columns. Unterminated or malformed quotes and duplicate headers, and rows with an unexpected column count reject the whole file; empty, header-only, and competing same-type files get a Heads-up. Header and status aliases are unverified against a real export (only the manual Jobs/Customers export is documented).
- Dates are shop-local (default America/Chicago) and validated against the calendar (2026-02-30 is rejected). Daylight-saving policy: a nonexistent spring-forward time moves forward by the gap, and an ambiguous fall-back time uses the first occurrence; both are counted in a Heads-up.
- Boundaries: an invoice is past due when today is at least `pastDueMinDays` (default 1) after the due date, so due today is not past due, and Paid, unsent, and void invoices never are; an estimate needs a real sent date, an awaiting-response-style status, a configured calendar-day cutoff (fictional sample uses 14), and a value at or above `estimateMinValue` (default 1000). Late jobs are computed from the scheduled end date.
- Slack text is escaped, stripped of control characters, and posted with Markdown, @-mention linking, and unfurls off; cell text is flattened to one line.
- Optional MAX API / webhook extension is a README note only: not implemented, paths unverified.
- Fictional fixtures ("Cedar Creek Plumbing & Air"): three sample CSV exports, a fixed reference time, and a generated `sample_morning_digest.md`.
- `mock_hcp_test.cjs` with 150+ assertions (workflow safety, CSV mapper, dates and DST, thresholds, queues, digest formatting, site copy, and the Code nodes run from the workflow JSON).
- Draft internal price recommendation (not approved for the site): $799 fixed install, optional $149/month retainer. The public site shows "Pricing coming soon".
- Still NOT tested against a live Housecall Pro, Gmail, or Slack account. The JSON and Code nodes were tested locally, with runtime import and delivery unverified.
