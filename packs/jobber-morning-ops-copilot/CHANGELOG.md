# Changelog

## v0.1.0 (draft)

- First draft of the Jobber Morning Ops Triage Copilot: a read-only weekday-morning digest for the owner that unifies (1) Unscheduled / Late / Action Required jobs, (2) Requires Invoicing jobs and past-due invoices, and (3) high-value quotes still awaiting a response after Jobber's native follow-ups, ranked by dollar value for a human call. This is a different pack from Jobber Connector, which drafts customer follow-ups.
- Two importable n8n workflows, built from `jobber_logic.cjs` by `build_workflow.cjs` and `build_csv_fallback_workflow.cjs`: `workflow.n8n.json` (21 executable nodes, 7 sticky notes; built-in sample, CSV, and a live read-only GraphQL path) and `jobber-csv-fallback-triage.json` (18 executable nodes, 6 sticky notes; webhook upload, inbound Gmail attachment, or watch folder; no HTTP Request node). Imported inactive; every Schedule, webhook, and Gmail trigger disabled; testMode on; source defaults to fictional sample data; owner-only delivery; placeholder credentials only.
- Zero write-back. The live path sends GraphQL queries only (GraphQL travels over HTTP POST; there is no mutation). No customer SMS, email, review request, On-My-Way text, or reminder blast. Deliberate Deletes: automated quote/invoice reminders, review requests, route-lock or schedule write-back, receptionist, QuickBooks Online sync, Zapier replacement.
- CSV mapper for Jobs, Invoices, and Quotes report exports: case/punctuation/space/underscore/hyphen-insensitive header aliases built from the column names on Jobber's help-center report pages, required-column validation with a plain-language Heads-up that lists the headers seen, and report detection by columns so file names do not matter. Malformed quoting and duplicate headers reject the whole file. Empty, incomplete, or competing snapshots get a Heads-up.
- Dates are shop-local (default America/Chicago) and validated against the calendar (2026-02-30 is rejected). Daylight-saving policy: a nonexistent spring-forward time moves forward by the gap, and an ambiguous fall-back time uses the first occurrence; both are counted in a Heads-up.
- Boundaries: an invoice is past due when today is at least `pastDueMinDays` (default 1) after the due date, so due today is not past due; a quote needs a real send date, a configured calendar-day cutoff beyond native follow-ups (fictional sample uses 14), and a value at or above `quoteMinValue` (default 1000). Drafts, approved, declined, converted, archived, and changes-requested quotes are ignored.
- GraphQL normalizer for jobs (including visits with null `startAt`/`endAt`), invoices, and quotes. Core object fields were checked against public documentation. The full queries, status values, connection behavior, and selected API version remain unverified in a live account; errors and missing data become Heads-up lines.
- Fictional fixtures ("Bluestem Home Services"): three sample CSV exports (32 rows), a mock GraphQL payload, a fixed reference time, and a generated `sample_morning_digest.md`.
- `mock_jobber_test.cjs` with 150+ assertions (workflow safety, CSV mapper, dates and DST, thresholds, queues, GraphQL, digest formatting, and the Code nodes run from the workflow JSON).
- Draft internal price recommendation (not approved for the site): $799 fixed install, optional $149/month retainer. The public site shows "Pricing coming soon".
- Still NOT tested against a live Jobber, Gmail, or Slack account. Some n8n parameters were cross-checked against upstream source. The JSON and Code nodes were tested locally, with runtime import and delivery unverified.
